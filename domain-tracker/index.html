This page tracks the journey of my custom domain from request to live. The checks below run live against public DNS every time you open or refresh this page.

  1. 1.Domain requested at eu.org

    ✓ Done

    dineshkumarmittapalli.eu.org was requested through the free eu.org registry (nic.eu.org).

  2. 2.eu.org approval & nameserver delegation

    Checking…

    eu.org is volunteer-run and approves domains in batches. Once approved, the nameservers kayleigh.ns.cloudflare.com and odin.ns.cloudflare.com must be saved at nic.eu.org so the domain appears on the internet.

  3. 3.Cloudflare DNS records

    ⏳ Added — waiting for delegation

    Four A records pointing to GitHub Pages (185.199.108.153, .109.153, .110.153, .111.153) plus a www CNAME to dineshkumar49m.github.io were added in Cloudflare. They go live automatically once the domain is delegated.

  4. 4.GitHub Pages custom domain + HTTPS

    ⏳ Waiting

    Once the domain resolves, it will be set as the GitHub Pages custom domain and free HTTPS (Enforce HTTPS) will be turned on. Every portfolio, blog, and GitHub link will then show only https://dineshkumarmittapalli.eu.org.

What happens when it goes live?

  • GitHub Pages is pointed at dineshkumarmittapalli.eu.org and free HTTPS is enforced.
  • Every link — portfolio, blog, GitHub profile — is updated so recruiters see only https://dineshkumarmittapalli.eu.org.
  • Until then, the portfolio stays live at dineshkumar49m.github.io.
